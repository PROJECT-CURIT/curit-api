## PoC 권장 범위

- 상품 10~20개, 작가 3명, 매장 3~5곳
- 굿즈 QR은 매장별 전시 상품 단위, 원화는 실물 단위로 발급
- QR 조회→상품 상세→주문 시작→완료 전환율 측정
- 매장별 재고 오차, 주문 전달 시간, 수령 확인 시간 기록
- 실제 과금 전에는 `PAYMENT_MODE=demo`와 “실제 결제 아님” 표시 유지

## 배포 시 환경변수

- QR 웹: `VITE_API_BASE_URL`, `VITE_PRESENTATION_MODE=false`
- API: `WEB_ORIGIN`, `PUBLIC_WEB_URL`, `SESSION_SECRET`, `DATABASE_URL`
- 실결제 준비 후: `PAYMENT_MODE=toss`, `TOSS_CLIENT_KEY`, `TOSS_SECRET_KEY`

키는 GitHub Actions Secrets나 배포 플랫폼의 비밀 저장소에만 보관합니다.
